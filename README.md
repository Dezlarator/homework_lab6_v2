Заданная область состоит из двух частей, объединенных логической операцией ИЛИ (`||`):

**1. Левая часть (треугольная область):**

$$
\begin{cases} 
-5 \le x \le 0 \\
y \le x + 5 \\
y \ge -x - 5
\end{cases}
$$

**2. Правая часть (четверть круга в первом квадранте):**

$$
\begin{cases} 
x \ge 0 \\
y \ge 0 \\
x^2 + y^2 \le 25
\end{cases}
$$

**Итоговое условие принадлежности точки $(x, y)$ области:**

$$
\text{inArea}(x, y) = \Big( (-5 \le x \le 0) \land (y \le x + 5) \land (y \ge -x - 5) \Big) \lor \Big( (x \ge 0) \land (y \ge 0) \land (x^2 + y^2 \le 25) \Big)
$$
**Итоговое условие принадлежности точки $(x, y)$ области:**
$$
\text{inArea}(x, y) = \Big( (-5 \le x \le 0) \land (y \le x + 5) \land (y \ge -x - 5) \Big) \lor \Big( (x \ge 0) \land (y \ge 0) \land (x^2 + y^2 \le 25) \Big)
$$

---

## ⚙️ Входные и выходные данные
- **Входные данные:**
  - `char c`: символ, выбранный пользователем для закраски области (например, `#`, `*`, `@`).
  - `double x, y`: вещественные координаты проверяемой точки.
- **Выходные данные:**
  - Текстовая ASCII-визуализация области в диапазоне $[-7, 7]$ по осям координат.
  - Сообщение о том, принадлежит ли точка области.

## 🧮 Контрольный пример
Для проверки корректности работы программы возьмем точку, которая гарантированно находится внутри четверти круга: **$x = 3, y = 4$**.

**Ручной расчет:**
1. Проверяем условие правой части: $x \ge 0$ ($3 \ge 0$, верно), $y \ge 0$ ($4 \ge 0$, верно).
2. Проверяем уравнение окружности: $x^2 + y^2 = 3^2 + 4^2 = 9 + 16 = 25$.
3. Условие $25 \le 25$ выполняется.

**Ожидаемый результат:** Программа должна вывести сообщение, что точка $(3, 4)$ **принадлежит** области, и отметить её символом `*` на графике внутри закрашенной зоны.

## 📊 Описание алгоритма (для блок-схемы)
<img width="661" height="1452" alt="Диаграмма без названия drawio (3)" src="https://github.com/user-attachments/assets/2d7647fe-a1aa-450c-a6c1-9eee46668e0b" />



Алгоритм отрисовки графика использует вложенные циклы и **строгий каскад приоритетов** при выборе символа для каждой ячейки сетки $(i, j)$:

1. **Начало** → Инициализация переменных, ввод символа закраски `c` и координат точки `(px, py)`.
2. **Внешний цикл:** `j` от $R$ (7) до $-R$ (-7) с шагом $-1$ (отрисовка строк сверху вниз).
3. **Внутренний цикл:** `i` от $-R$ (-7) до $R$ (7) с шагом $+1$ (отрисовка столбцов слева направо).
4. **Каскад условий выбора символа `out`:**
   - **Приоритет 1:** Если `hasPoint` и `i == pi` и `j == pj` → `out = '*'` (точка пользователя).
   - **Приоритет 2:** Иначе, если `inArea(i, j)` истинно → `out = c` (закрашенная область).
   - **Приоритет 3:** Иначе, если `i == 0` и `j == 0` → `out = '+'` (начало координат).
   - **Приоритет 4:** Иначе, если `i == 0` → `out = '|'` (ось Y).
   - **Приоритет 5:** Иначе, если `j == 0` → `out = '-'` (ось X).
   - **Приоритет 6 (иначе):** → `out = '.'` (пустой фон).
5. Вывод символа `out` в консоль.
6. Конец внутреннего цикла (`i++`).
7. Если `j == 0`, вывести букву `x` (подпись оси). Вывод перевода строки `\n`.
8. Конец внешнего цикла (`j--`).
9. Вывод числовой подписи оси X.
10. **Финальная проверка:** Если точка была введена, вызвать `inArea(px, py)` и вывести текстовый вердикт ("принадлежит" / "не принадлежит").
11. **Конец**.

## 💻 Структура программы
Программа реализована в модульном стиле:
- `int inArea(double x, double y)`: Чистая функция, инкапсулирующая математическую логику проверки. Возвращает `1` (истина) или `0` (ложь). Не содержит операций ввода/вывода.
- `int main(void)`: Управляет потоком выполнения, вводом данных, отрисовкой сетки и финальным выводом.
