## 📝 Постановка задачи
Составить программу на языке C, которая:
1. Проверяет, принадлежит ли точка с заданными пользователем координатами $(x, y)$ заданной заштрихованной области (согласно варианту).
2. Позволяет пользователю интерактивно выбрать символ для визуализации (закрашивания) области.
3. Выводит на экран ASCII-график области с отмеченной пользовательской точкой и текстовое сообщение о результате проверки.
4. Содержит **контрольный пример** с ручным расчетом для верификации алгоритма.

---

## 📐 Математическая модель
Заданная область состоит из двух частей, объединенных логической операцией ИЛИ (`||`):

1. **Левая часть (треугольная область):**
   $$
   \begin{cases}
   -5 \le x \le 0 \\
   y \le x + 5 \\
   y \ge -x - 5
   \end{cases}
   $$

2. **Правая часть (четверть круга в первом квадранте):**
   $$
   \begin{cases}
   x \ge 0 \\
   y \ge 0 \\
   x^2 + y^2 \le 25
   \end{cases}
   $$

**Итоговое условие принадлежности:** `inArea = (Условие 1) || (Условие 2)`

---

## ⚙️ Входные и выходные данные
- **Входные данные:**
  - `char c`: символ, выбранный пользователем для закраски области (например, `#`, `*`, `@`).
  - `double x, y`: вещественные координаты проверяемой точки.
- **Выходные данные:**
  - Текстовая ASCII-визуализация области в диапазоне $[-7, 7]$ по осям координат.
  - Сообщение о том, принадлежит ли точка области.

---

## 🧮 Контрольный пример
Для проверки корректности работы программы возьмем точку, которая гарантированно находится внутри четверти круга: **$x = 3, y = 4$**.

**Ручной расчет:**
1. Проверяем условие правой части: $x \ge 0$ ($3 \ge 0$, верно), $y \ge 0$ ($4 \ge 0$, верно).
2. Проверяем уравнение окружности: $x^2 + y^2 = 3^2 + 4^2 = 9 + 16 = 25$.
3. Условие $25 \le 25$ выполняется.

**Ожидаемый результат:** Программа должна вывести сообщение, что точка $(3, 4)$ **принадлежит** области, и отметить её символом `*` на графике внутри закрашенной зоны.

---

## 💻 Структура программы
Программа реализована в модульном стиле:
- `int inArea(double x, double y)`: Чистая функция, инкапсулирующая математическую логику проверки. Возвращает `1` (истина), если точка внутри, и `0` (ложь) в противном случае. Не содержит операций ввода/вывода (`printf`/`scanf`).
- `int main(void)`: Управляет потоком выполнения:
  1. Инициализация русской локали (`setlocale`).
  2. Запрос символа для закраски и координат точки.
  3. Вложенные циклы `for` для отрисовки сетки координат. Приоритет отрисовки: пользовательская точка $\rightarrow$ область $\rightarrow$ оси координат $\rightarrow$ фон.
  4. Финальный вывод текстового вердикта.
